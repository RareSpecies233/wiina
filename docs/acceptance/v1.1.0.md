## 变更范围

1. **F11 提示浮窗**：移除 OSC 全屏按钮上的 `全屏 (F11)` tooltip，只保留无障碍名称。
2. **浅色模式 OSD**：`ApplyTheme` 同时给 `Osd` 设置 `RequestedTheme`，并在
   `ActualThemeChanged` 时同步，避免首次注入后仍是深色样式。
3. **快速设置顶部两层**：侧边栏类型页签和快速设置页签都改为 WinUI 下划线页签
   （透明底、选中项 accent 文字 + 2 px accent 下划线）。
4. **HiDPI 裁切**：音量滑杆宿主加宽到 94 DIP、左右各留 12 DIP，避免最大值滑块
   圆点被裁切；浮动 OSC 改为 `MinWidth/MinHeight`，时间行改 Auto + MinHeight，
   底部 OSC 也可随文字缩放增高。
5. **自动播放列表**：设置 → 通用 → 播放列表 → 自动添加播放列表。默认同目录文件，
   可选仅手动、同目录及子文件夹；打开单个视频时把同目录媒体追加到列表，当前文件
   仍在首位。
6. **关于界面**：圆形/圆角白色品牌底 + `Assets/wiina.png` 黄色三角形；背景改为
   `WindowTintBrush`，透出 Windows App SDK acrylic。
7. **设置界面**：移除左上角齿轮；搜索框移入扩展标题栏；左右两栏都透明，主体只
   使用同一层 `WindowTintBrush`，不再有 rail/page 的亮度差和分隔线。
8. **标题栏按钮**：自定义最小化/最大化/关闭按钮改为 40 DIP 满高，hover/pressed
   背景覆盖整行。
9. **OSC 展开菜单置顶**：菜单顶部新增“置顶/取消置顶”快捷项，并保留分隔线。

## 已知限制

- Windows App SDK 仍会随包附带 `RestartAgent.exe`（SDK 2.0 的进程重启助手）。
  Wiina 未调用 `AppInstance.Restart`，该文件目前未被使用；移除它不影响本版本，
  后续可在打包脚本中排除。
- 预览缩略图由后台 ffmpeg 缓存生成，快速扫过时可能滞后一帧；卡片定位已使用
  内容尺寸，不累积偏移。
