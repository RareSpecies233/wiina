## 用户问题清单（1.3.8）

| # | 问题 | 结论 | 证据 / 说明 |
| --- | --- | --- | --- |
| 1 | 设置窗口已打开时再次进入设置，页面/滚动位置被重置 | ✅ 已修复 | 根因：`App.ShowSettingsWindow` 的入参默认值是 `SettingsPageId.General`，任何“打开设置”都当成深链导航。新增 `src/Wiina.Core/Settings/SettingsNavigation.cs`：`Decide(windowOpen, page, rowId)` 区分 `ActivateExisting`（普通打开只前置，保留页面/滚动/展开状态）与 `NavigateThenActivate`（显式页/行才导航）；首次创建用 `InitialPage`（请求页优先，否则上次页）。`App.xaml.cs:548-579` 改为 `ShowSettingsWindow(SettingsPageId? page = null, string? rowId = null)`；菜单与欢迎页的普通打开改为无参调用（`MainWindow.Menu.cs:1063`、`WelcomeWindow.xaml.cs:166`）；行级深链保留当前页（`existing.NavigateTo(page ?? existing.CurrentPage, rowId)`）。新增 8 个 `SettingsNavigationTests`（普通打开不动、显式页导航、仅行深链导航、首次开页、上次页回退、`ParsePage` 大小写/回退）。 |
| 2 | 全屏下 OSC 侧栏/快速菜单点不动 | ✅ 已修复（真鼠标复现并验证） | 根因：v1.3.7 的 `OnRootGotFocus` 焦点守卫在 pointer press 时把焦点抢回 `RootGrid`，WinUI 因此取消按钮 `Click`（侧栏页签、开关、ComboBox、滑杆全部中招）。修复 `src/Wiina.App/MainWindow.Playback.cs:2177-2187`：`control.FocusState == FocusState.Pointer` 时直接 `return`，不再抢指针焦点；键盘 `Tab` 仍由 `OnRootPreviewKeyDown` 拦截。证据 `artifacts/v138-bugA-combo-fullscreen.png`、`v138-bugA-after-toggle.png`、`v138-bugA-fullscreen-after-tabclick.png`（真全屏，页签/开关/ComboBox 弹层/滑杆可用）。 |
| 3 | PiP 占位层「恢复画中画」按钮无反应 | ✅ 已修复（真鼠标复现并验证） | 根因：`VideoFrame` 的 `OnVideoPointerPressed` 以 `handledEventsToo:true` 注册，PiP 下仍启动拖动手势并抢焦点，按钮的 pointer capture 被取消、`Click` 不触发。修复 `src/Wiina.App/MainWindow.Playback.cs:2546-2556`：`if (InPipMode) return;`。证据 `artifacts/v138-bugB-pip-placeholder.png` → `v138-bugB-restored.png`（真鼠标点击后 2 窗变 1 窗、主窗 1920×1080、视频回主窗）。 |
| 4 | 缩略图生成慢（macOS 15 s vs 本机 30–50 s） | ✅ 方案报告已交付；**未实施** | 新增 [缩略图 v1.3.8 改造方案](../reports/thumbnails-v1.3.8-plan.md)（360 行）：慢速模式三套语义互相打架的根因、有效模式/磁盘缓存策略、关键帧 seek 开关（`video.thumbnail-keyframe-seek`，默认关）、即时模式 UX 状态机（`ThumbnailOutcome`，无转圈/保留上一帧）、macOS 与本机的差距拆解（张数 2.85×、hwdec 回退假设、20 ms 轮询地板）、实施顺序与测试方案。本轮不改代码。 |
| 5 | 文档与计数同步 | ✅ | 本轮复核设置 **11 页 / 132 行 / 581 键**、英文覆盖 **132/132**、动作行 **31**；相对链接全量自检通过。 |

## 已知限制

- 全屏与 PiP 两项修复均为**真鼠标复现后修复**，但只在单屏 2560×1325 @ 100% DPI 下验证；高 DPI 与多屏的命中/焦点行为未复测。
- 迷你播放器侧栏未单独回归；它与全屏共用 `OnRootGotFocus` 守卫，但“同一守卫”不等于“已验证”。
- 设置窗口的 `ActivateExisting` 只保留页面/滚动/展开状态；若窗口已被关闭再打开，仍按“请求页 → 上次页”规则，不恢复滚动位置（滚动位置未持久化）。
- 缩略图方案全部未实施：关键帧开关、慢速模式重构、即时模式 UX、20 ms 轮询地板都还是报告里的路线。
- 光标隐藏仍未解决，不要在任何文档里写“已修复”。
- 909 项测试为维护者构建实跑结果，本轮文档未构建、未复跑。
