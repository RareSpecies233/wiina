```powershell

dotnet test tests/Wiina.Core.Tests/Wiina.Core.Tests.csproj -c Release

# 应用（Release / x64 / self-contained）
dotnet build src/Wiina.App/Wiina.App.csproj -c Release -p:Platform=x64

# 或使用固定的开发构建脚本
pwsh -File scripts/dev-build.ps1 -Agent docs

# 便携 zip（含便携卸载器，校验 Wiina.dll 版本 == 1.2.7）

pwsh -File scripts/release.ps1 -Version 1.2.7
```

## 已知限制

1. **缩略图缓存**：键含文件大小与 mtime，文件被原地替换且大小/mtime 不变时可能命中旧帧；超出预算按 LRU 清理，旧文件在长时间不播放后才会被回收；拖动进度条没有节流，悬停请求只靠“插队 + 丢弃陈旧结果”；网络/UNC 源不落盘。
2. **光标隐藏**：`ShowCursor` 计数是线程本地的，若在隐藏状态下被强杀进程，系统计数理论上会残留（进程退出后由系统回收，不影响其他程序）。
3. **管理员关联**：仍需 Windows“默认应用”确认，`UserChoice` 受保护时可能清不掉；便携版移动目录后需重新关联。
4. **全屏边框**：DWM 圆角/边框属性在 Windows 10 上会被忽略（无副作用），仅 Windows 11 22000+ 生效。
5. 缩略图与性能数字来自维护者实测与报告；711 项测试已由 Lead 在打包前复跑（见上）。
