## 已知限制

- 小窗内控件的键盘不可达是有意为之：Tab 在小窗/全屏会被收回 `RootGrid`，避免 Space/Enter 误触按钮。
- 浅色小窗底图为静态检查（Light/Dark/HighContrast 三套画刷齐备），本轮未逐主题截图验收。
- 丢帧提示的位置按代码核对（正中央）；视觉遮挡情况待人工过一遍。
- 830 项测试为 task-54 的实跑结果，本文档轮未重新构建、未复跑。
- 版本文件在文档撰写时仍为 1.3.2（`Directory.Build.props:7`、`Branding.cs:8`、`PackageManifest.cs:11`/`:17`、`app.manifest:3`、`package.ps1:28`、`wiina.iss:36`）；打包前由维护者升到 1.3.3，产物名按 1.3.3。
