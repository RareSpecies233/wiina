## 构建与测试

```powershell
# Core 测试
dotnet test tests/Wiina.Core.Tests/Wiina.Core.Tests.csproj -c Release

# 应用（Release / x64 / self-contained）
dotnet build src/Wiina.App/Wiina.App.csproj -c Release -p:Platform=x64

# 或使用固定的开发构建脚本
pwsh -File scripts/dev-build.ps1 -Agent docs

# 便携 zip（含便携卸载器，校验 Wiina.dll 版本 == 1.2.4）
pwsh -File scripts/package.ps1 -Version 1.2.4

# 安装包（在便携 zip 之后；需要 Inno Setup 6）
pwsh -File scripts/release.ps1 -Version 1.2.4
```

> 不要用 `dotnet build Wiina.slnx -p:Platform=x64`：当前 SDK 不识别该平台名，请按上面的项目构建。

## 验收清单（本轮 10 项用户问题）

| # | 用户问题 | 结果 | 证据 |
|---|---|---|---|
| 1 | 毛玻璃要可开关，纯色档完全不能透出内容，且纯色档不要有抓帧/模糊开销 | **待验** | 设置 → 界面 → 窗口与 OSC → 毛玻璃模式（行 id `ui.blur-mode`）：固定/动态/始终/关闭毛玻璃（纯色），默认动态。前三档走 `Interop/ChromeBlur.cs`（125 ms、320 px 降采样、Win2D 高斯 9）；纯色档 `ChromeBlur.SetMode(Solid)` 不建 Win2D 设备、不启动 worker，只画 `ChromeSolidBrush` + 16% accent（`Services/ChromeTint.cs`）。`WIINA_BLUR_DISABLE=1` 强制纯色。OSD 文本在所有档位不透明；Docked 布局标题栏也不透明（视频在栏下方） |
| 2 | 吸附要真的贴边、不留白；拖任意区域都吸附；吸上要能拿下来 | **待验** | `Core/State/FrameMargins.cs` + `WindowInterop.TryGetFrameMargins`（`DWMWA_EXTENDED_FRAME_BOUNDS`，按 DPI 缓存）把外框矩形换算成 DWM 可见边框后再吸附；10 DIP 吸附 / 22 DIP 脱离迟滞；标题栏 `WM_MOVING`、视频区域拖动、迷你播放器、PiP 四条路径都接入（`MainWindow.xaml.cs` / `PipWindow.xaml.cs` 的 `SnapMargins`）；吸附时 `ApplySnapFrame(true)` 去掉 DWM 边框线与圆角，脱离恢复。`FrameMarginsTests` / `EdgeSnapTests` 覆盖换算与迟滞 |
| 3 | 小窗放大后只有窗口变大、内容不缩放；迷你窗也要能吸附 | **待验** | `PipGeometry.RenderSize` 已取消 640×360 上限，返回整窗物理像素；`PipWindow.UpdateSurface` 用 `MpvVideoView.SetLayoutSize` 保持 XAML 面板为整窗尺寸并只做裁剪；`MainWindow.Modes.cs` 把 RenderSize 直接写入 `d3d11-composition-size`。小窗只靠简化 UI 省开销，不再降采样放大。迷你播放器拖动也使用共享 `EdgeSnapSession`。`RenderSizeTests` 覆盖 |
| 4 | 动画相关的提问（关闭 Windows 动画后，快速设置页仍有动画，播放列表/章节/插件没有） | **如实回答：本版未改动** | 代码里 `QuickSettingsView.AnimatePageChange` 与 `SettingsWindow.AnimatePageChange` 只判断应用内的“启用动画”设置，没有读取系统 `UISettings.AnimationsEnabled`，所以关闭 Windows 动画后布局/视频/音频/字幕仍会上滑淡入；播放列表/章节/插件页只是切换 `Visibility`，本来就没有 storyboard，因此“没有动画”。侧栏滑入用的是 `SidebarState.ResolveAnimation(app, system)`，会跟随系统开关。若需要这四页也跟随系统动画，可作为后续改动 |
| 5 | 设置左栏未点开的项悬停不应变亮 | **待验** | `SettingsWindow.xaml` 的 `SettingsNavButtonStyle` 自定义 `ControlTemplate`：`PointerOver`/`Pressed` 为空状态，静止与悬停像素一致（暗色 `SecondaryTextBrush`、无填充/边框），仅选中项染色，键盘焦点为 2 px accent 环；`SettingsWindow.xaml.cs` 的 `NavForegroundBinding` 把图标/文字 Foreground 绑到按钮，消除主题回退色造成的“假高亮” |
| 6 | 画质预设里 upscale/downscale/chroma 是裸 mpv 名；去色带应独立且默认关 | **待验** | `SettingsCatalog` 的 `video.quality` 只剩 默认 / 性能优先 两项；`VideoQualityPreset.Balanced/HighQuality` 仅为旧 JSON 反序列化保留并归一化为 默认；管理窗口保留可读标签 + 取舍说明 + tooltip 原始键名。`video.deband` 移到 视频 → 画面，`AppSettings.DebandEnabled` 默认 `false`，切换时 `MainWindow.Sidebar.cs` 立即 `deband=yes/no`。`QualitySettingsTests` 覆盖归一化 |
| 7 | mpv 统计要立即出现、信息完整，不能只有 dropped | **待验** | 原生 `PlaybackStatsPanel` + `MainWindow.Stats.cs`：启用/启动立即填充（不等第一帧），1 秒刷新，5 组 29 行（文件 3 / 视频 9 / 音频 4 / 播放 7 / 渲染 6）。`MainWindow.Osd.cs` 的 `UpdateStatsPlacement` 让卡片跟随 OSD 六向位置；`RequestedTheme` 随根主题切换，深色下文字可读。持久技术 OSD（`AppSettings.OsdPersistent`、`ui.osd-persistent`、`utilities.technical-osd`、快速设置开关）已整体移除，统计卡片是唯一统计界面 |
| 8 | 要安装包；卸载时应能选择保留配置 | **待验** | `installer/wiina.iss`（按用户、`PrivilegesRequired=lowest`、默认 `%LOCALAPPDATA%\Programs\Wiina`、中英向导）；卸载 `KeepUserDataPrompt` 询问「是否保留配置文件？」，默认保留，静默保留；选“否”只删 `%LOCALAPPDATA%\Wiina`、`Wiina.*` classes/OpenWith 值、`RegisteredApplications\Wiina`、`HKCU\Software\Wiina`，不碰媒体。便携 zip 附带 `Uninstall Wiina.exe`（`--silent --keep-config/--remove-config --remove-associations --dry-run` 等），安装版排除它。详见 [../installer.md](../installer.md) |
| 9 | mpv 画质选项很多，为什么现在只能调 4 个？ | **如实回答：不是只有 4 个，只是内置预设只保留 2 套** | 内置预设是“缩放器组合”，不是 mpv 全部画质开关：默认（`ewa_lanczos` / `mitchell` / `bilinear`）与性能优先（`bilinear`×3）。要在 mpv 的 9 种缩放器里自由选择，请打开 视频 → 画面 → 管理画质预设，那里 upscale / downscale / chroma 三级各自可选 9 个缩放器，也可导入/导出自定义 JSON；`deband` 已拆到独立开关。mpv 还有 `tscale`、`vd-lavc-*` 等未暴露的选项，避免把上百个参数直接铺进 GUI |
| 10 | 设置页签归位与精简（审计） | **待验** | 见下节“设置页签审计”；设置仍为 12 页 / 121 行，行 id 不变 |

## 已知限制

- 三个玻璃档有真实成本：每 125 ms 一次 `screenshot-raw`（1280×720 约 45 ms / 3.7 MB，
  720p 下约三分之一个核心）；纯色档为零。OSD 文本在所有档位保持不透明；Docked 布局
  标题栏不透明。
- 吸附按 DWI 可见边框计算，DPI 与窗口变化会失效缓存；混合 DPI 多显示器移动仍需人工确认。
- 文件关联只能把 Wiina 变成候选处理程序，默认程序仍要在 Windows“默认应用”里确认；
  功能更新后 Windows 可能重置默认值。
- Windows 10 上标题栏自定义 API 不可用时退回系统标题栏。
- 便携卸载器自删除依赖批处理重试；文件被占用时以退出码 1 结束并提示手动删除。
- 两个产物均未签名，SmartScreen 可能提示；无 MSIX / 自动更新。
