| # | 问题 | 结论 | 证据 / 说明 |

| 1 | 毛玻璃按整个窗口绘制，视频有黑边时被拉伸/错位 | ✅ 已实现并截图验证 | 新增 `src/Wiina.Core/Playback/VideoDisplayRect.cs`：`TryFromOsd` 读取 mpv `osd-dimensions`（`w/h/ml/mt/mr/mb`），按窗口 `RasterizationScale` 换成 DIP，对边距做 2 px / 2 % 合理性检查，异常时回退到等比适配矩形（`Fit`/`Clamp`）。`ChromeBlur` 只在该矩形内绘制。实测 506×993 窗口、16:9 内容、100% DPI：修复前模糊区域 `504x992`（`k = 1.575, 5.506`）；修复后 `504x283`、起点 `(0, 354)`（`k ≈ 1.573`），黑边保留纯色 tint。证据：`artifacts/blur5-before-*.png` / `blur5-after-*.png`（标题栏、上下 OSC、高窗口、暗色窗口）。`WIINA_BLUR_LOG=1` 输出 `display/fromMpv`。限制：150% DPI 与 PiP 未单独实测，panscan/zoom 产生负边距时走等比回退。 |
| 2 | 进度条缩略图带字幕 | ✅ 已确认真实 bug 并修复 | 根因：headless 提取实例也带 `sub-visibility=yes`，且 `screenshot-raw` 默认把字幕烧进画面。修复：headless 增加 `sub-visibility=no`、`sub-auto=no`、`sid=no`、`secondary-sid=no`、`osd-bar=no`，`ScreenshotRaw` 支持显式传 `"video"` 标志（`src/Wiina.App/Services/ThumbnailService.cs:1060`）。像素对比：同一 Hibike 文件 600 s 处，修复前缩略图含字幕行，修复后干净，与 `screenshot-raw video` 的平均绝对差 0.2022。这不是用户误判。 |
| 3 | 小窗在浅色主题下发黑/配色不一致 | ✅ 已实现（产品选择） | 小窗固定深色 chrome：`MiniPlayer.RequestedTheme = Dark`（`src/Wiina.App/MainWindow.Modes.cs:559`）、根节点 `#FF08090A`（`:567-568`）、进入时挂起系统背景（`:512-518`）并在退出时恢复（`:614`、`:620-623`）。正文对比度约 18:1、次要文字约 9:1。证据：`artifacts/mini-t62dark-*.png` 与 `mini-t62light-*.png` 同场景哈希一致。这是有意的 IINA 风格设计，不是跟随系统主题的回归；若以后要跟随浅色，需要单独的一套浅色 token。 |
| 4 | 缩略图只能全片预生成，低配机卡顿 | ✅ 已实现（代码路径 + 轨迹验证） | 新增 `video.thumbnail-mode`（`SettingsCatalog.cs:249`，预生成（推荐）/ 即时预览）与 `video.thumbnail-hover-delay`（`:258`，0–2000 ms，步进 50，默认 250，仅即时预览使用）；`ThumbnailMode` 枚举 `src/Wiina.Core/Settings/ThumbnailMode.cs:14`，上限 `ThumbnailPolicy.MaxHoverDelayMilliseconds`。即时预览不预生成、不读不写磁盘缓存、不按全片定容内存缓存；悬停时只取最后停留的位置。轨迹验证：`thumbnail mode: instant`、0 条 pre-generation 记录、磁盘文件数 3082 前后不变。限制：自动化验证走的是代码路径，未用物理指针逐像素比对。 |
| 5 | 贴边吸附时窗口抖动 | ✅ 已复现并修复（CSV 证据） | `EdgeSnap.Apply` 只接受原始拖动矩形（不再以已吸附矩形为基准累加偏移），在整数物理像素内按 10 DIP 吸附、22 DIP 断开；主窗口与 PiP 用锚点 + 光标位移跟踪，位置未变就不调 `Move`，DWM 状态只在切换时设置，并加 16 ms 拖拽泵在指针捕获丢失时继续跟踪（`MainWindow.Playback.cs` 拖拽逻辑、`MainWindow.xaml.cs:2504`）。证据：`artifacts/t62-content-rel4.csv` 等——贴边时可见间隙 0、35 帧静止不变、回拖 23 px 可见位移后断开。限制：100% DPI 单屏实测。 |

## 已知限制

- 毛玻璃矩形：150% DPI 与 PiP 未单独实测；panscan/zoom 产生负边距时回退到等比适配矩形。
- 缩略图字幕修复是像素级对比（单文件、单时间点），未覆盖所有字幕类型（ASS/图形字幕）。
- 即时预览模式的验证是代码路径 + 轨迹，不是物理指针逐像素比对；悬停延迟只在即时预览下生效。
- 吸附抖动修复在 100% DPI 单屏实测；16 ms 拖拽泵在极慢机器上可能滞后一两帧。
- 光标隐藏仍未解决，不要在任何文档里写“已修复”。
- 857 项测试为维护者构建实跑结果，本轮文档未构建、未复跑。
