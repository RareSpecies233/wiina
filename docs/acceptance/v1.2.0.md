## 1.1.2 回归修复

1. 快速设置页签切换后，只保留当前项底部高亮；非当前页只显示图标，当前页显示图标 + 文字。
2. 侧栏打开时，标题栏/OSC 的自动隐藏计时器与指针离开路径都会跳过，避免操作模式被中途隐藏。
3. 关闭按钮改为 `×`；页签图标略放大，导航项仍保持紧凑。
4. 移除 `Escape` 的 XAML KeyboardAccelerator，保留键位表处理，消除偶发 `Esc` 提示浮窗。

## 1.2.0 新功能

1. **PiP/小窗**：拖动条、双击提示、播放条仅在鼠标移入时显示；关闭按钮保留；
   原“返回”按钮改为置顶切换；播放/暂停图标随真实播放状态更新。
2. **边缘吸附**：拖动窗口/小窗后，靠近屏幕边缘 24 px 自动吸附；设置 → 通用
   “贴边吸附”可关闭。
3. **智能字幕**：`SmartSubtitleFinder` 新增 IINA 风格宽松匹配，忽略 1080p、x265、
   WEB-DL 等发布标签，同时避免跨集误配；新增两个 Core 测试。
4. **画质预设**：mpv 缩放/去色带预设（自动 / 均衡 / 高质量 / 性能优先），
   设置 → 视频 → 视频画质预设；OSC 更多菜单可直接切换。
5. **毛玻璃性能模式**：设置 → 界面 → 玻璃性能模式（固定帧 / 动态 / 始终计算）；
   默认动态只在 titlebar/OSC 可见时采集，固定帧在显示时只采集一次。
6. **设置页切换动画**：页面切换加入 160 ms 淡入 + 轻微上滑，可通过“界面动画”关闭。
7. **快捷键编辑器**：键位使用 WinUI 圆角键位胶囊显示；修改后列表与提示立即更新。

## 已知限制

- 当前验收环境未切换系统 200% 缩放；所有 DIP 几何按比例缩放，如特定缩放仍见裁切，
  请附截图与缩放比例继续处理。
- 全屏游戏 + 始终置顶小窗的卡顿与 Windows DWM/游戏独占呈现相关，无法只靠应用层完全消除。
  可在设置中把“玻璃性能模式”改为“固定帧”，或关闭动态模糊以降低 GPU/合成开销；
  本版本未实现游戏进程识别或独占全屏强制绕过。
- 毛玻璃仍是 8 fps、320 px 重采样的近似实时帧，不是 DWM 逐像素 acrylic。
