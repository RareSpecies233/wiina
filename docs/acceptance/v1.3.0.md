## 已知限制

- 冻结问题未完全闭环：R2（GPU 设备丢失后无重建）与 8 Hz 全帧回读仍在；R1（关闭竞态）已在 1.2.7 修复并沿用。详见 [冻结分析](../reports/ui-freeze-analysis.md)。
- 缩略图“慢速模式”是单线程低优先级，首次悬停仍比常规模式慢；磁盘缓存按文件大小/修改时间/时长做键，文件被外部修改后会重新生成。
- mpv.net 导出为**可选实验**：`mpv.conf` 只接受选项，快捷键必须写在 `input.conf`；Wiina 侧栏、OSD、合成相关选项在 mpv.net 中不可用。
- 文件关联仍需在 Windows「默认应用」中确认；安装版只写 HKLM 需管理员（UAC）确认。
- 安装包未签名，SmartScreen 会提示；详见 README 的 SmartScreen 小节。
