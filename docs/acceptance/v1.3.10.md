## 构建与测试

```powershell
$dotnet = "$env:USERPROFILE\.dotnet\dotnet.exe"   # 10.0.402

& $dotnet build src/Wiina.App/Wiina.App.csproj -c Release -p:Platform=x64
& $dotnet build tests/Wiina.Core.Tests/Wiina.Core.Tests.csproj -c Release

# 本机 vstest testhost 无法打开父进程句柄（Win32Exception 5），因此用
# in-process xunit runner 跑同一份编译产物；runner 是本地 harness，不提交。
& $dotnet artifacts/testrunner/wiina-testrunner.dll artifacts/testrunner/Wiina.Core.Tests.dll

pwsh -File scripts/release.ps1 -Version 1.3.10
```

### 实现范围说明（以代码为准）

- 媒体键只改**内置 Wiina 方案**；自定义方案里用户手动加过的绑定不会被清理。
- 防休眠不修改系统电源计划、不阻止手动锁屏（Win+L），只在「有媒体且未暂停」时持有；组策略强制无人参与超时可能覆盖应用请求。
- 看门狗依赖 mpv 的 `estimated-frame-number`；如果某个 mpv 构建把它报告为 0/-1，看门狗不会触发（fail-safe），音频文件也不会触发。
- 官方 `dotnet test` 在本机受 vstest testhost 限制（`Win32Exception (5)` 打开父进程句柄），验收使用同编译产物的 in-process xunit runner；该 runner 不属于仓库代码。
