## 构建与测试

```powershell
# Core 测试
dotnet test tests/Wiina.Core.Tests/Wiina.Core.Tests.csproj -c Release

# 应用（Release / x64 / self-contained）
dotnet build src/Wiina.App/Wiina.App.csproj -c Release -p:Platform=x64

# 或使用固定的开发构建脚本
pwsh -File scripts/dev-build.ps1 -Agent docs

# 便携 zip（含便携卸载器，校验 Wiina.dll 版本 == 1.2.5）
pwsh -File scripts/package.ps1 -Version 1.2.5

# 安装包（在便携 zip 之后；需要 Inno Setup 6）
pwsh -File scripts/release.ps1 -Version 1.2.5
```

> 不要用 `dotnet build Wiina.slnx -p:Platform=x64`：当前 SDK 不识别该平台名，请按上面的项目构建。

## 验收清单（本轮 4 项用户问题）

| # | 用户问题 | 结果 | 证据 |
|---|---|---|---|
| 1 | 深/浅色切换只刷新一部分窗口：设置里切浅色后播放窗口没变，快速菜单切深色后设置窗口没变 | **待验** | `App.ResolveTheme` 为 `ThemeMode.System` 解析出具体 `ElementTheme`（`UISettings.GetColorValue(UIColorType.Background)`），`ApplyThemeToOpenWindows` 遍历播放窗口与全部辅助窗口调用 `WindowShell.ApplyTheme`；`SettingsWindow`/`MainWindow`/`PipWindow` 各自的 `ApplyTheme` 在内存里先应用再 `App.SyncOpenWindowThemes()`，不必等防抖保存。`MainWindow.ApplyTheme` 同时刷新 `Osd.RequestedTheme`、PiP 与 `ChromeTint.Recolor()`。`ThemeMode.System` 经 `ColorValuesChanged` 实时跟随 Windows 应用主题。限制：Mica/亚克力材质可能晚一帧；高对比度下的深浅切换未做视觉验证 |
| 2 | 毛玻璃切到「纯色」仍能透出视频；纯色深色底太黑 | **待验** | 外框面板不再由代码写 `Background`：`ChromeSolidBrush` 保留在 XAML，模糊层/tint 层是子元素，只切换 `Visibility`（`OscBottomView`/`OscFloatingView`/`TitleBarView`/`SidebarHost`/`OsdText` 的 `ApplyBlurVisuals`）。深色基色 `ChromeTint.DarkBase` 与 `Tokens.xaml` 改为 `#FF202227`，深色 tint（`#99202227`/`#B3202227`/`#A6202227`）同步对齐；纯色仍混 16% 系统 accent。`ChromeBlur.SetMode` 可在运行时切换档位，Solid 不建 Win2D 设备、不启 worker |
| 3 | OSD 也应毛玻璃，并与全局毛玻璃模式一致 | **待验** | `Controls/OsdText.xaml(.cs)` 增加 `BackdropBlurHost` + `OsdBlurTintLayer`，以半径 12 调用 `ChromeBlur.TryAttach`，监听 `ChromeBlur.ModeChanged`：固定/动态/始终显示玻璃，纯色档不透明；OSD 仍 `IsHitTestVisible=false`，淡入淡出动画不变 |
| 4 | 画质管理加更多 mpv 选项，默认对齐 IINA，性能优先也要更新 | **待验** | `VideoQualityProfile` 扩展为 23 项（缩放 7、色度 2、抖动 4、去色带 5（含总开关语义）、插帧 2、同步 2、其他 1），`VideoQualityProfiles.CreateDefault` 对齐 mpv 0.41 默认（IINA 的 `MPVOptionDefaults.swift` 不覆盖这些值）；`CreatePerformance` = bilinear ×3、`dither=no`、三个质量开关全关、去色带/插帧关；`ToMpvOptions` 按安全顺序下发 24 个键（去色带 4 参数仅在总开关开启时）；旧名 `自动（IINA 默认）`/`均衡`/`高质量` 归一化为「默认」；未知导入键保留。另修复 `VideoQualityWindow.xaml` 9 个 `NumberBox` 缺少 `Grid.Column="1"` 导致微调按钮压住标签的布局缺陷 |

## 画质选项清单（默认档 vs 性能优先）

默认档即 mpv 0.41 的默认值（IINA 不覆盖）；性能优先只改能稳定省 GPU 的项目。

| 分组 | 中文名 | 原始 mpv 键 | 默认 | 性能优先 | 说明 |
|---|---|---|---|---|---|
| 缩放 | 放大缩放 | `scale` | `lanczos` | `bilinear` | 锐利 vs 最省 |
| 缩放 | 缩小缩放 | `dscale` | `hermite` | `bilinear` | 平滑、不易闪烁 |
| 缩放 | 放大抗振铃 | `scale-antiring` | `0` | `0` | 抑制白边，>0 会略软 |
| 缩放 | 缩小抗振铃 | `dscale-antiring` | `0` | `0` | 同上，缩小方向 |
| 缩放 | 正确缩小 | `correct-downscaling` | 开 | 关 | 先线性缩小再重采样，多一次采样 |
| 缩放 | 线性亮度缩放 | `linear-downscaling` | 开 | 关 | 暗部过渡更自然 |
| 缩放 | 平滑放大（S 曲线） | `sigmoid-upscaling` | 开 | 关 | 抑制放大光晕 |
| 缩放 | 仅缩放时启用缩放器 | `scaler-resizes-only` | 开 | 开 | 避免无谓重采样 |
| 色度 | 色度缩放 | `cscale` | `bilinear` | `bilinear` | 只影响彩边 |
| 色度 | 色度抗振铃 | `cscale-antiring` | `0` | `0` | 彩边白边抑制 |
| 抖动 | 抖动算法 | `dither` | `fruit` | `no` | 掩盖 8bit 色带 |
| 抖动 | 抖动位深 | `dither-depth` | `auto` | `auto` | 按面板位深 |
| 抖动 | 抖动范围 | `dither-size-fruit` | `6` | `6`（`dither=no` 时不生效） | 越大越均匀、略慢 |
| 抖动 | 时间抖动 | `temporal-dither` | 关 | 关 | 逐帧噪点，静态渐变更平滑 |
| 去色带 | 去色带（总开关） | `deband` | 关（设置 → 视频 → 画面） | 关 | 只有开关打开时才下发 |
| 去色带 | 迭代次数 | `deband-iterations` | `1` | `1` | 越大越慢，4 以上收益递减 |
| 去色带 | 阈值 | `deband-threshold` | `48` | `48` | 太高误伤细节 |
| 去色带 | 范围 | `deband-range` | `16` | `16` | 参与判断的像素半径 |
| 去色带 | 颗粒 | `deband-grain` | `32` | `32` | 补回颗粒，过大显噪点 |
| 插帧 | 插帧 | `interpolation` | 关 | 关 | 明显增加 GPU 负载 |
| 插帧 | 时间缩放 | `tscale` | `oversample` | `oversample` | 插帧时的帧混合算法 |
| 同步 | 同步策略 | `video-sync` | `audio` | `audio` | 本地播放默认即可 |
| 同步 | 最大视频变速 | `video-sync-max-video-change` | `1.0` | `1.0` | 超出则丢/重复帧 |
| 其他 | GPU 省电模式 | `gpu-dumb-mode` | `auto` | `auto` | 空闲时降 GPU 占用 |

内置预设仍只有两套：**默认 · 内置** 与 **性能优先 · 内置**（UIA 核对）。设置页仍为
12 页 / 121 行，行 id 未变（1.2.6 新增自动隐藏延迟一行后为 122 行）。

## 已知限制

- 主题切换时窗口材质（Mica/亚克力）可能晚一帧重绘；高对比度下深浅切换未做视觉验证。
- 毛玻璃三档仍有 ~8 fps `screenshot-raw` 回读成本（45 ms / 3.7 MB 每 1280×720 帧）；纯色档为零。
- Docked 布局标题栏保持不透明（视频在栏下方）；OSD 在纯色档不透明。
- 安装包未签名；文件关联只写 HKCU，Windows 仍需在“默认应用”里人工确认。
- 统计面板的行标签与分组名固定为中文（标题/副标题/关闭按钮已本地化）。
