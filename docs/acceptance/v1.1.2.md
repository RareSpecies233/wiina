## 变更范围

1. **原生音量条**：`VolumeSlider` 改回 WinUI 3 原生 `Slider`，轨道 85 DIP（相对上一版 94 DIP
   为 90%），左右各 8 DIP padding 给系统 Fluent 圆点留出完整空间；滑块保持原生模板，
   不再使用自绘椭圆。0% / 100% 两端都验证无横线露出。
2. **系统 accent**：`Tokens.xaml` 的 `AccentBrush` / `SidebarRowCurrentBrush` 改为
   `{ThemeResource SystemAccentColor}`，OSC 音量、页签下划线、置顶图钉、开关与 OSD
   进度条跟随系统强调色（当前系统为橙色），不再写死蓝色。
3. **OSC 按钮顺序**：全屏按钮与播放列表按钮交换。
4. **单层快速设置导航**：删除 `QuickSettingsView` 内部第二层页签；`SidebarHost` 顶部
   使用单行 7 项定位：布局 / 视频 / 音频 / 字幕 / 播放列表 / 章节 / 插件，均为图标 + 文字
   并带底部 accent 高亮。类别行仅在非快速设置模式显示，快速设置模式只显示这一行。
5. **关闭与切换**：只有左上角关闭按钮会关闭侧栏；顶部类别/页面切换只切换内容，不关闭。
6. **缩小导航控件**：关闭按钮 24×24 DIP，导航行高 30 DIP、字号 10、图标 10，
   整行居中对齐。
7. **操作模式**：打开快速设置时，`HasVisibleSidebar` 阻止标题栏/OSC 的自动隐藏；
   关闭后恢复原自动隐藏设置。

## 已知限制

- 当前验收环境未切换系统 200% 缩放；原生 Slider 的 padding 与 DIP 几何按比例缩放，
  如特定缩放仍可见裁切，请附截图与缩放比例继续处理。
- 原生 Slider 的 focus 边框在键盘/辅助功能聚焦时会出现；这是 WinUI 的系统行为，
  不影响鼠标操作。
- 模糊仍是 8 fps、320 px 重采样的近似实时帧；UI 层不是逐像素 DWM acrylic。
